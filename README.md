# HoloFriend

HoloFriend is a Java desktop virtual pet game inspired by classic virtual pet games. Take care of Shirakami Fubuki, earn coins by fishing and spend them on food and furniture!

![HoloFriend demo](gif.gif)

## Features

Virtual Pet System — Take care of Fubuki and manage her hunger and stamina.

Fishing System — Catch fish and earn coins.

Shop System — Spend your earnings on food and other items.

Interactive Furniture — Interact with furniture in your virtual environment.

Customisation — Unlock and change Fubuki's outfits.

Hololive Collaborations — Invite other Hololive members.

Save System — Persistent game data.

Custom Pixel Art — Handcrafted pixel-art assets and animations.

Windows Integration — Integration with the Windows desktop.

Localisation — English and Japanese language support.

## Download

Download the latest Windows build from GitHub Releases.

Platform: Windows (tested). Support for other operating systems is untested.
